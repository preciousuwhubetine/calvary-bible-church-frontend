### Project Overview

This project is the official website for Calvary Bible Church, built using React.js and Vite.

### Project Setup

1. Clone the repository:

  ```bash
   git clone
  ```

2. Install dependencies:

  ```bash
   npm install
  ```

3. Start the development server:

  ```bash
   npm run dev
  ```
